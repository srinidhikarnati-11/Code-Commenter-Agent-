# Code Commenter Agent

## Project Description
Code Commenter Agent is an AI-based web application that generates comments and explanations for source code to help developers understand their programs easily.

## Features
- Generates code comments.
- Explains code in simple language.
- Improves code readability.
- Helps students learn programming.

## Live Demo
https://codecommenter-new.vercel.app/

## Purpose
This project helps programmers understand code and makes learning programming easier.
